# Monthly Bill Checklist

Western-style monthly bill tracker (static HTML/CSS/JS). Saves on-device via `localStorage`.

## Open the checklist

- **Live app:** https://bill-checklist.apps.grok.bot
- **Android-friendly share link** (use this in texts / WhatsApp): https://is.gd/zv42xb  
  Some Android phones show “cannot find appropriate application” for `.bot` links from Messages. The short link opens in the browser first, then loads the checklist.
- **GitHub Pages** (after enabling Pages once in repo Settings → Pages → GitHub Actions): https://lisadelga.github.io/bill-checklist/

## Files

- `index.html` — layout
- `styles.css` — western poster theme
- `app.js` — bills, specialty payments, spending trackers, persistence
