# Monthly Bill Checklist

Western-style monthly bill tracker (static HTML/CSS/JS). Saves on-device via `localStorage`.

## Share with Android (do not text a long URL)

Many Android phones **cannot send or open** `*.apps.grok.bot` links from Messages (“cannot find appropriate application” / link won’t send).

### Best options for Lisa’s sister

1. **Send a photo** — text/MMS the QR share card: `open-checklist-share-card.png`  
   She opens Camera / Google Lens and scans it.
2. **Email the file** — attach `monthly-bill-checklist.html` (opens in Chrome from Gmail/Drive).
3. **Type this in Chrome** (no link to tap):  
   `cottony-share-f8kfe.ship.place`

### Other URLs

- Classic-domain host: https://cottony-share-f8kfe.ship.place/
- Cursor live app (iPhone OK): https://bill-checklist.apps.grok.bot
